        t[k+1] = t[k]->u   if z[k] = 0
        t[k+1] = t[k]->v   if z[k] = 1

    So t tells us where z belongs in the next column.

    3. Insert one new node for z into each linked list.

    4. Set z's own u/v pointers.

    5. Fix nearby u/v pointers above z that should now point to z.

    6. Backward sweep:
        compute z's divergence with node above
        update divergence of node below
